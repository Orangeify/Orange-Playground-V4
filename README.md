# Deployment

> [!IMPORTANT]
> This website uses backend proxying, and therefore is NOT a static site. If you want to deploy this to static services (e.g. Vercel, Netlify, GitHub Pages etc.) , use [this repo instead]().

```

cd Orange-Playground-V4
npm install
npm start
```
